# Open Grip Board App
Companion app for the open grip board.

## Status
| Platform |   Status    |
|:---------|:-----------:| 
| android  |   ongoing   | 
| ios      | not started |
| web      | not started |

### Features
#### V1.0
- [x] scan open grip board hardware QR-Code and connect to Hangboard
- [x] record data while training on the hangboard
- [ ] basic statistics from past trainings

#### V1.1
- [ ] control hangboard from the app i.e. weight cell calibration.
- [ ] Define your own Training routines
- [ ] train with different hold types and sizes
